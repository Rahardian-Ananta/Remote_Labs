Tentang RemoteLab v2.0

RemoteLab adalah platform eksekusi kode terdistribusi berbasis web yang mengadopsi antarmuka modern Google Colab.

  • Arsitektur: Hybrid Master-Slave & Chord DHT 32-bit.
  • Komunikasi: JSON-RPC 2.0 via HTTP.
  • Paralelisasi: MPI (Message Passing Interface via mpi4py).
  • Ketahanan: Heartbeat failover (<1s) & LRU Edge Caching.
